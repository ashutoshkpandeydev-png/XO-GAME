# 🎮 XO-GAME (Tic Tac Toe)

A sleek, responsive, and easy-to-play **Tic Tac Toe (X & O)** web game with zero external dependencies.

Live Demo: [https://ashutoshkpandeydev-png.github.io/XO-GAME/](https://ashutoshkpandeydev-png.github.io/XO-GAME/)

---

## ✨ Features

- **3 Game Modes**:
  - 🤖 **vs Computer (Easy)**: Casual AI that makes casual moves and occasional blocks.
  - 🧠 **vs Computer (Smart)**: Minimax AI that plays optimally.
  - 👥 **2 Players (Local)**: Classic pass-and-play on the same device.
- **Scoreboard**: Tracks Player X wins, Player O wins, and Draws.
- **Sound Effects**: Audio synthesized using the browser's Web Audio API with a toggle button.
- **Modern UI**: Dark aesthetic with neon accents and animations.
- **Python Version**: Includes a standalone `game.py` for terminal gameplay.

---

## 🚀 How to Run Locally

### Option 1: Browser (Recommended)
Simply open `index.html` in any browser or double-click `play.bat` on Windows.

### Option 2: Python Terminal
```bash
python game.py
```
